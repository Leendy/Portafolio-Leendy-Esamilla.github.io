# 🚀 Portafolio Personal - Leendy

Bienvenido a mi portafolio personal donde muestro mis proyectos, habilidades y experiencia como desarrollador.

## 📋 Descripción

Este portafolio web presenta mis trabajos más destacados, certificaciones y habilidades técnicas. Está construido con tecnologías web modernas para ofrecer una experiencia de usuario óptima.

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos y animaciones
- **JavaScript** - Interactividad
- **jQuery** - Manipulación del DOM

## 📁 Estructura del Proyecto

```
PortafolioMio/
├── index.html          # Página principal
├── css/
│   ├── css.css         # Estilos principales
│   └── normalize.css   # Reset de estilos
├── js/
│   ├── main.js         # JavaScript principal
│   └── jquery-3.3.1.min.js
├── img/
│   ├── certificados/   # Imágenes de certificaciones
│   └── proyectos/      # Capturas de proyectos
├── pdf/
│   └── CV_LKEC.pdf     # Curriculum Vitae
└── audio/              # Archivos multimedia
```

## 🚀 Cómo usar

1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. Navega por las diferentes secciones del portafolio
